# 阅兵动画：25 秒制作计划

确定主题「阅兵动画」：以天安门与广场为背景，组合坦克、队列、红旗和飞机。当前默认加载完整广场及真实军人 OBJ；人物仍是静态 T 姿态平移，坦克独立履带部件采用循环程序纹理模拟滚动，尚非链节几何运动。广场原配 MTL 缺失，需补充。主题按课程要求与老师确认。

| 时间 | 画面规划 | 技术任务 |
| --- | --- | --- |
| 0～5 秒 | 远处向城楼推进 | 平滑镜头插值 |
| 5～10 秒 | 四种坦克通过 | 多 OBJ、MTL 颜色、整体位移 |
| 10～15 秒 | 真实人物队列平移 | 后续补骨骼或分肢步态 |
| 15～20 秒 | 风中旗帜特写 | 细分网格、顶点形变、法线更新 |
| 20～25 秒 | 抬头看飞机编队 | Bézier 物体路径、PNG 纹理 |

## 模块边界

- `code/include/Timeline.hpp`：纯数学、时长、路径；不要在这里调用 OpenGL，便于测试。
- `code/src/main.cpp`：当前负责场景与主循环；场景复杂后再提取 Scene/Camera/Texture，不提前搭空类。
- `code/src/Mesh.cpp`：OBJ → 三角形顶点 → VAO/VBO；按 MTL 材质分批绘制，支持漫反射图片和颜色。
- `code/src/Shader.cpp`：shader 文件编译、链接与 uniform。
- `code/shaders/`：坐标变换、光照、贴图和后续高级纹理。
- `model/`：正式模型、贴图与来源记录。原始素材不在运行时修改。

## 推荐顺序

1. 每位组员先成功构建同一版本，测试通过，再分支开发。
2. 完善天安门与广场场景，统一人物的尺度、朝向和脚底原点。已有军人素材为 FBX，当前加载器只支持 OBJ；需转换为可用 OBJ，或另行实现骨骼模型加载。静态 OBJ 不保留骨骼动画，步态需要可动肢体或其他动画方案。
3. 外部图片加载已加入；后续完善城楼材质、透明材质和光照。
4. 先让单个人物完成步态，再复制为方队并整体匀速移动；按绝对时间组织分镜和 Bézier 镜头，保证暂停/重播一致。行进速度与步长匹配，避免滑步。
5. 当前已加入地面高度图凹凸贴图，B 键切换对比；环境贴图未实现。后续若加入切线空间法线贴图，需要正确 TBN。
6. 录屏工具录制完整动画；程序当前没有视频导出功能。整理报告、运行说明和素材许可。

## 验收

- 干净克隆到另一台组员机器后可以按 README 构建。
- 控制台没有 shader 编译或 OBJ 加载错误，模型法线、贴图与光照方向正确。
- 动画时长 20～30 秒；暂停、重播和结束行为明确。
- 能解释 shader pipeline、Phong 的三项和 Bézier 控制点；高级纹理如未做不得在报告中声称完成。
