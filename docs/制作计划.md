# 25 秒动画制作计划

暂定主题「元宵灯会：一盏灯的旅程」。当前程序只是技术占位，各分镜需要后续实现，不能把下面的规划当作已有功能。

| 时间 | 画面规划 | 技术任务 |
| --- | --- | --- |
| 0～5 秒 | 庭院全景，灯笼轻摆 | 正式场景、镜头建立、Phong 调参 |
| 5～15 秒 | 主灯笼沿曲线穿过灯阵 | Bézier 位置、朝向、速度曲线 |
| 15～22 秒 | 镜头跟随，展示纸面与木构细节 | UV 图片贴图，可选法线贴图 |
| 22～25 秒 | 拉远收束，画面稳定停留 | 镜头衔接、收尾、录制 |

## 模块边界

- `code/include/Timeline.hpp`：纯数学、时长、路径；不要在这里调用 OpenGL，便于测试。
- `code/src/main.cpp`：当前负责场景与主循环；场景复杂后再提取 Scene/Camera/Texture，不提前搭空类。
- `code/src/Mesh.cpp`：OBJ → 三角形顶点 → VAO/VBO；目前不自动加载 MTL，也不按子材质分批绘制。
- `code/src/Shader.cpp`：shader 文件编译、链接与 uniform。
- `code/shaders/`：坐标变换、光照、贴图和后续高级纹理。
- `model/`：正式模型、贴图与来源记录。贴图外部文件加载器尚待添加。

## 推荐顺序

1. 每位组员先成功构建同一版本，测试通过，再分支开发。
2. 替换占位模型并完成传统文化主题场景，先保证尺度、UV 和构图正确。
3. 加入外部纹理图片加载，完善光照与材质，让基础评分项完整可见。
4. 按绝对时间组织分镜，完成一条完整 25 秒叙事；暂停/重播时状态一致。
5. 时间允许再做法线贴图或环境贴图。法线贴图需要切线空间 TBN，不能只多采样一张图片。
6. 录屏工具录制完整动画；程序当前没有视频导出功能。整理报告、运行说明和素材许可。

## 验收

- 干净克隆到另一台组员机器后可以按 README 构建。
- 控制台没有 shader 编译或 OBJ 加载错误，模型法线、贴图与光照方向正确。
- 动画时长 20～30 秒；暂停、重播和结束行为明确。
- 能解释 shader pipeline、Phong 的三项和 Bézier 控制点；高级纹理如未做不得在报告中声称完成。
